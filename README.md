# Dashboard de Produtividade

Dashboard interativo desenvolvido em Python para visualizar e analisar registros de atividades e produtividade.

## Tecnologias

- Python
- pandas
- Streamlit

## Funcionalidades

- Indicadores de horas e atividades
- Taxa de conclusão
- Filtro por categoria
- Filtro por status
- Filtro por período
- Horas por categoria
- Evolução de horas por dia
- Visualização dos registros

## Executando localmente

```bash
pip install -r requirements.txt
streamlit run app.py
